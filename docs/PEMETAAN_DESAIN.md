# Pemetaan 15 Desain ke Aplikasi

1. Pengunjung Beranda → `?page=home`
2. Pengunjung Informasi Pupuk → `?page=informasi`
3. Pengunjung Login → `?page=login`
4. Pengunjung Registrasi → `?page=register`
5. Petani Dashboard → `?page=farmer_dashboard`
6. Petani Profil → `?page=profil`
7. Petani Katalog Pupuk → `?page=katalog`
8. Petani Pesanan → `?page=pesanan_saya`
9. Admin Dashboard → `?page=dashboard`
10. Admin Data Petani → `?page=admin_petani`
11. Admin Data Pupuk → `?page=admin_pupuk`
12. Admin Laporan → `?page=admin_laporan`
13. Petugas Scan QR → `?page=scan_qr`
14. Petugas Validasi → `?page=validasi&kode=KODE`
15. Petugas Konfirmasi → tombol konfirmasi pada hasil validasi

Halaman tambahan: kategori, stok, detail pesanan, pembayaran, riwayat, pengaturan.

## Halaman tambahan hasil penyempurnaan
- Admin verifikasi petani → `?page=admin_petani` (tombol Verifikasi/Nonaktifkan pada setiap baris).
- Admin kategori pupuk → `?page=admin_kategori`.
- Admin manajemen stok → `?page=admin_stok`.
- Admin transaksi → `?page=admin_pesanan`.
- Admin akun pengguna → `?page=admin_users`.
- Petani pembayaran → `?page=pembayaran`.
- Petani riwayat transaksi → `?page=riwayat`.
- Petani ubah profil → `?page=profil`.
- Detail pesanan dan QR → `?page=detail_pesanan&id=ID`.
